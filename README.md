# Habit Tracker API - Backend

API RESTful para aplicación de seguimiento de hábitos, desarrollada con Express.js y MongoDB Atlas.

## 🚀 Características

- CRUD completo para hábitos
- Sistema de rachas (streaks)
- Seguimiento de progreso hacia 66 días
- Conexión a MongoDB Atlas
- Endpoints para marcar hábitos como completados

## 📋 Prerrequisitos

- Node.js (v14 o superior)
- npm o yarn
- Cuenta en MongoDB Atlas
- Postman o Insomnia para probar endpoints
