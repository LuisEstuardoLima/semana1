# Habit Tracker - Aplicación Completa

Aplicación web para seguimiento de hábitos basada en el libro "Hábitos Atómicos" de James Clear.

## 📋 Estructura del Proyecto

- **/backend**: API RESTful con Express.js y MongoDB
- **/frontend**: Aplicación cliente con Next.js y Redux

## 🚀 Tecnologías

### Backend
- Express.js
- MongoDB Atlas / MongoDB en memoria
- Mongoose
- CORS

### Frontend
- Next.js 14
- React 18
- Redux Toolkit
- Tailwind CSS
- Axios

## 📦 Instalación

### Backend
```bash
cd backend
npm install
cp .env.example .env
# Configurar variables de entorno
npm run dev
